# 首页设计规范

## 设计原则

1. **克制** — 不做多余的装饰，每个元素都有明确的功能目的
2. **朴实** — 避免花哨的渐变和动画，用清晰的视觉层级传达信息
3. **适用** — 符合工具类产品的使用场景，不追求营销感
4. **容易理解** — 用户一眼就能识别功能，不需要猜测
5. **印象深刻** — 通过细节的精致感建立品牌记忆

## Logo 规范

### 当前问题
- 56×56 圆角方块，内部字母 "O" 过于简单
- 缺乏品牌识别度，与通用图标难以区分
- 没有传达产品特性（会议、录音、转写）

### 设计方向
- 保持简洁，但增加辨识度
- 可以通过负空间、几何组合传达「对话」「声音」概念
- 尺寸适中，不抢占功能入口的视觉权重

## 功能入口规范

### 麦克风录音（主要功能）
- **视觉权重最高** — 这是核心功能，需要最突出
- **状态感知** — 有录音任务时显示「返回录音」，无任务时显示「麦克风录音」
- **快捷键** — ⌘R（录音）应在空间允许时可见

### 上传音频文件（次要功能）
- **视觉权重次之** — 辅助功能，不抢主要功能的风头
- **清晰标识** — 上传图标需要明确表达「文件」概念
- **快捷键** — ⌘U（上传）应在空间允许时可见

## 布局规范

### 垂直层级
1. Logo（品牌识别）
2. 主标题（功能说明）
3. 功能按钮（操作入口）
4. 最近会议（快捷访问）

### 间距节奏
- Logo 与标题：`var(--s-6)` (24px)
- 标题与按钮：`var(--s-2)` (8px)
- 按钮与最近会议：`var(--s-7)` (48px)

## 交互规范

### 按钮状态
- **默认态** — 清晰的视觉区分（主要/次要）
- **悬停态** — 背景色变化 + 轻微位移（translateY(-1px)）
- **按下态** — 位移回弹（translateY(0)）
- **禁用态** — 降低透明度，不可点击

### 动画原则
- 页面加载：从下往上淡入，错开延迟
- 按钮交互：150ms 过渡，不拖沓
- 背景装饰：缓慢流动，不干扰注意力
