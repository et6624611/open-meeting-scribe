# ADR-0018 本地可选计算引擎与声纹离线化

- 状态：Proposed（2026-09-23 起草，随功能落地转 Accepted/Implemented）
- 日期：2026-09-23
- 决策人：Yongliang Wang（裁决要点 D1/D2，见需求记录）
- 相关：[ADR-0001](0001-mvp走云方案.md)、[ADR-0002](0002-asr选paraformer-v2.md)、[ADR-0003](0003-纪要选qwen-plus.md)、[ADR-0005](0005-说话人姓名化方案选型.md)、[ADR-0009](0009-声纹识别服务云端拆分.md)、[ADR-0012](0012-ASR转写走云端代理.md)、[ADR-0015](0015-本地优先原则重定义与引流授权服务.md)、[REQUIREMENT_LOCAL_ENGINE.md](../REQUIREMENT_LOCAL_ENGINE.md)

## 背景

### 商业动因

GitHub 开源前竞品调研（2026-09-23）显示：开源会议纪要品类的第一心智已被 Meetily（31,044★）锁定为「100% 本地、零云依赖」；本项目 ASR/LLM/声纹均依赖云端（DashScope / asr-proxy / voiceprint-service），对涉密会议用户与国际开发者存在采用天花板——录音音频上传与 ADR-0015「业务数据永不落地」承诺之间存在语义张力（数据不落地 ≠ 数据不出设备）。

### 技术前提

- MVP_PLAN 曾预留「FunASR + pyannote + Ollama」作为 v2 备选，未实施。
- ADR-0009 将声纹 embedding 提取拆到 voiceprint-service 的**首要动机是包体**：torch（~543MB）占总包体 60%+，拆云后 Windows 精简版从 ~600MB 降至 ~200MB。注册表当时已设计为云端 `cam++-v1-cloud` 与本地 `cam++-v1` 双向兼容。
- 本地 ASR（FunASR paraformer）**必然重新引入 torch 依赖**。torch 一旦因 ASR 回到本地引擎组件，ADR-0009 的拆云动机在离线模式下即告失效——声纹本地化（复用被移除的 CAM++ 本地推理路径，28MB 权重）边际成本趋近于零。

## 决策

### D1：MVP = 本地 ASR 落地；LLM 侧用户自接，不托管

1. 计算能力层新增**可选**本地引擎：ASR 与说话人分离由本地 FunASR（paraformer 离线模型 + 本地分离）承担，转写结果对齐 `API_CONTRACTS.md` 统一契约。
2. 纪要/洞察 LLM 侧**仅支持**用户自配 OpenAI 兼容端点（Ollama、LM Studio 等：base_url / model / 可选 key，含连通性测试与预设）；本项目**不包含**本地大模型的下载、安装、版本托管。
3. 默认引擎不变：云端（体验代理 / 自持 DashScope Key）仍是首启默认，本地引擎为显式选择。ADR-0001/0002/0003/0012 对云模式继续有效，本 ADR 不推翻。

### D2：离线模式下声纹回归本地 CAM++

1. 本地引擎模式下，声纹注册与批处理匹配走本地 CAM++（ModelScope `iic/speech_campplus_sv_zh-cn_16k-common`），**不调用** voiceprint-service；补齐断网闭环。
2. **部分修订 ADR-0009**：其「本地不跑声纹推理」约束仅在本地引擎模式下不再适用；云端模式拆分架构与部署维持原状。
3. 沿用 ADR-0009 的注册表双向兼容承诺：同批注册数据在 `cam++-v1-cloud` / `cam++-v1` 间切换零迁移。
4. 实时聚类的本地 MFCC 降级链路不变（不为实时侧恢复 torch 依赖），离线模式实时转写仍按需求记录「分段批处理降级」执行。

## 后果

### 正面

- 「数据主权本地」从主张升级为可验证事实：断网全流程零出网请求（localhost 除外），支撑涉密/政企场景与 README 合规叙事。
- 零配置可用性：用户不注册任何云服务即可完成录音→纪要闭环（LLM 端点自备），显著降低开源场景「clone 即试」门槛。
- 声纹能力在离线模式完整保留，与 Meetily 类纯本地方案形成对等基础上的 CJK 差异化。

### 负面与代价

- torch/funasr 依赖回归：本地引擎组件体积显著增加。缓解：本地引擎作为可选组件分发，云端模式安装包保持 ADR-0009 精简成果；两套分发物规格在文档中显性声明。
- 双引擎矩阵抬高测试面：转写契约、声纹注册表兼容、失败回退需纳入 CI（当前仅冒烟测试）。
- 本地小模型（用户自接）纪要质量低于 qwen-plus，需「联网提质」回云路径与提示词降级调优对冲。
- ModelScope 模型权重许可需逐模型核查分发方式（采用引导下载而非内置分发），THIRD_PARTY_NOTICES 相应增补。
