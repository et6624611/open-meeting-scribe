# Insight Deck 画布改造 — 实施交接件（workflow 阶段卡样式）

- 状态：方案已获批准（用户确认样机 `docs/insight-deck-mockup.html`）
- 实施方：Qoder IDE　｜　规划/跟踪：项目管理员 Waker
- 预估：约 11h　｜　版本：v1.0（2026-09-23）

## 1. 目标

将录音页洞察台（Insight Deck）展开态画布从「G6 圆点关系图」改为 QoderWake workflow 样式：

- 点阵背景画布，阶段卡从左到右排布，允许错行；
- 阶段卡 = 编号（阶段 NN）+ 加粗标题 + 描述（≤2 行截断）+ 步骤芯片堆叠；
- 步骤芯片 = 单行标题（省略号截断）+ 子行（图标 + 归属 + 时间戳）；
- 连线仅水平/垂直直角段，**无箭头端点**；
- 左下角缩放控件：适应画布 / 缩小 / 放大 / 全屏；
- 保留现有能力：芯片点击跳转转写（seekTo）、hover tooltip、明暗主题。

## 2. 核心设计决策（已定，勿再讨论）

**输入契约采用大模型原生的受约束 Mermaid，不自定义嵌套 JSON。**

1. AI 仍只输出 `diagram` 字段（Mermaid 文本），**删除 `graph` JSON 字段**及其提示词段落（`core/insights.py` 第 81–91 行附近的「结构化知识图谱」节）。
2. 提示词中对 `diagram` 增加「洞察台画布书写规范」（见 §3）；规范不满足时前端自动降级。
3. 前端新增解析层：从 Mermaid 文本提取 subgraph/节点/边 → 内部结构 → 自绘 DOM 卡片 + SVG 连线。
4. 降级路径：解析失败 → 用现有 `MermaidDiagram.vue` 直接渲染原始 Mermaid（用户永远有图看）。

## 3. Mermaid 书写规范（写入提示词）

```
flowchart LR
  subgraph S1["数据核对"]
    S1a["拉取费控数据 @@84000"]
    S1b["确认统计口径 @@461000"]
  end
  subgraph S2["差异讨论"]
    S2a["差旅超支归因 @@903000"]
  end
  S1a --- S2a
```

硬性约束（解析器依赖）：
- 方向固定 `flowchart LR`；
- 每个 `subgraph` = 一个阶段，ID 形如 `S<序号>`，标题为 ≤6 字的阶段名；
- 阶段编号（"阶段 01"）由前端按序号自动生成，**不写入标题**；
- 节点 ID 形如 `S<序号><字母>`，标签 ≤14 字；
- 节点标签尾部用 ` @@<毫秒数>` 携带转写定位时间（无时间则省略），前端渲染时剥离该标记并显示为 `mm:ss`；
- 阶段间用 `---`（无箭头）连接不同 subgraph 内的节点，前端聚合为阶段级连线；禁止使用 `-->`；
- 阶段 2–5 个，每阶段节点 1–4 个，总节点 ≤12；
- 阶段描述：模型在 `body`（图注）中按「阶段名：一句话」逐段给出，前端按阶段名匹配填入卡片描述；匹配不到则该卡不显示描述（合法降级）。

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 模型不遵守书写规范 | 降级到 MermaidDiagram 原生渲染；T1 用真实样本迭代提示词，达标线 80% |
| `@@` 标记与标签文本粘连解析错误 | 解析器用尾部正则 ` @@(\d+)$`，只剥离末尾一处 |
| 阶段卡溢出并排态窄面板 | T3 内置 autoFit 初始缩放，放大后才允许平移 |
| 历史会议数据含 graph 字段 | T5 保留读取兼容：有 graph 无 diagram 时仍走旧 InsightGraph 或按 §4-T5 规则降级（实现方二选一并记录） |
| 描述匹配失败率高 | 已定义为合法降级（卡片不显示描述），不阻塞 |
