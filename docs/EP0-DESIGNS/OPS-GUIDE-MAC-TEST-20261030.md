## 操作步骤（约 20 分钟）

### 第 1 步 · 打开 Docker Desktop
在"应用程序"里启动 Docker Desktop，等右上角鲸鱼图标变绿（就绪）。

### 第 2 步 · 拿到安装包
浏览器打开：
https://github.com/et6624611/open-meeting-scribe/actions/runs/40897084410
页面拉到 Artifacts 区，下载 `oms-private-package-0.0.0-ci`（zip 约 580MB，含全部镜像，离线可用）。
⚠️ 当前网络实测下载较慢（约需 1~2 小时）。DevOps 已在后台同步下载，下载完成我会在群里播报——您也可以自己让浏览器挂着下。

### 第 3 步 · 安装（下载完成后）
解压 zip 得到一个文件夹，进"终端"App 执行（把路径换成您解压的实际位置）：

```
cd ~/Downloads/oms 解压目录
./oms-offline-install.sh
```

看到"安装完成"和访问地址打印即成功。若报 `address already in use`，先执行下面两行换端口再重跑：

```
echo "OMS_PORT=18000" >> .env
./oms-offline-install.sh
```

### 第 4 步 · 初始化（4 步向导）
在这台 Mac 的浏览器打开 `http://localhost:8000`（换过端口则是 `http://localhost:18000`）：
设管理员账号（13373013103）→ 确认访问地址 → 生成第一张邀请码。

### 第 5 步 · 四个体验确认点
产品经理已给逐屏指引，照做即可。两个 Mac 特有提示：
- 确认点③"手机访问"：手机地址要用 Mac 的局域网 IP，终端执行 `ipconfig getifaddr en0` 获取（形如 192.168.x.x），手机浏览器输 `http://<那个IP>:8000`（安装脚本打印的 127.0.0.1 只能本机用，见差异①）；手机需和 Mac 连同一个 Wi-Fi。
- 确认点②"改录音存放位置"需要助手在线：个人版应用即助手，装好打开即可；如员工设置页显示"未检测到手记助手"，在"高级→助手地址"确认端口一致。

### 老数据迁移（可选）
按包内 README-admin 第 3 节命令执行；Mac 上把"把老数据拷到服务器"理解为"拷到这台 Mac 的解压目录 old-data"即可。

## macOS 与 Ubuntu 的三处已知差异（都不改主脚本）

① **同事访问地址显示**：Mac 没有 `hostname -I`，脚本自动回退打印 `http://127.0.0.1:8000`。
   给同事/手机的地址请手动用 `ipconfig getifaddr en0` 查出的 IP。功能完全不受影响。

② **升级/回滚脚本**（oms-upgrade.sh）用了 Linux 版 sed 语法，Mac 上会失败。
   Mac 体验阶段不需要跑升级（升级/回滚已在 Linux CI 实机验证并留证）。若一定要在 Mac 演练，告诉我，我给逐条手敲的等价命令。

③ **端口占用**：本机 8000 已有其他服务（您机器上正在跑的开发服务）。用第 3 步的换端口两行即可，企业版本身无冲突。
