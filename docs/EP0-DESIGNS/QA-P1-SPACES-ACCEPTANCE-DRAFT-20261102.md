## 一、验收域 TA：团队维度越权矩阵（A 系扩展，team × 角色展开）

### TA1 矩阵维度

| 维度 | 枚举 |
|---|---|
| 资源 R | 团队实体（详情/成员列表/改名/归档）、团队副本（纪要/决策/笔记/洞察 的 读/列表/编辑/删除条目/公开/撤回）、决策条目级公开与撤回、团队词表（team_assets）、发言人别名（团队面，U4=只读）、变更记录（changelog）、企业资产层后台记录（enterprise_decision_assets） |
| 角色 X | 非本团队成员（含同实例其他团队成员）、只读 viewer、可编辑 editor、团队 admin、旧管理员（转让后）、**实例管理员（P0 admin）**、停用账号（status=disabled）、匿名/无令牌、篡改 team_id/role 的 JWT |
| 空间上下文 S | 私有空间原件、团队 A 内容（调用者为团队 B 成员）、已撤回副本、归档团队内容、含 formal/audio 的构造请求 |

### TA2 判定规则（错误码语义按契约 §8 定版：成员门槛不足=403 明示语义；非成员=404 防枚举；禁 5xx、无半泄漏）

1. **跨团队隔离**：非本团队成员（含团队 B 成员、实例管理员、匿名）对团队 A 任何资源全操作 → **404**（防枚举，P0 同尺）；列表接口不得出现他团队条目任何字段（含标题预览）；篡改 team_id/role 的 JWT → 401。
2. **三档权限逐格**：**团队内**角色不足写操作 → **403**——viewer 一切写（编辑/删除条目/公开/撤回/词表编辑/成员管理）→ 403；editor 内容写放行但成员管理/改名/归档/转让 → 403；team admin 全队治理权但**不得**改写任何成员的私有空间原件（发布=副本语义，跨面写私有原件 → 403/404 按归属语义，出现 2xx 即 FAIL）。
3. **实例管理员边界延续（Q2 裁决同尺）**：P0 admin 对团队空间**内容**默认不可读——按 §一-1 归入"非成员=404"单分支展开；其可见**元数据**（团队数/成员数/资产计数，契约 §2）用例断言=元数据端点响应不含任何内容字段（标题/正文/决策文本零命中）。团队层不得成为企业面的旁路读通道。
4. **撤回语义（按契约 §3.3 修正）**：owner 可撤回自己发布的副本；**团队 admin 可撤回任意副本（治理出口，合法放行）**；editor 撤回他人发布 → 403。撤回后团队全员读/写该副本 → 404；副本 status='deleted' 软删、资产行转 withdrawn、留痕完整；私有原件零影响。
5. **修改留痕可证伪且全员可见（Q4 裁决落地）**：每次团队面内容操作产生 team_edit_audit 行（actor_user_id、rev、action、content_hash 指针，不存正文）；留痕不可被 editor 删改；变更记录端点对团队全员（含 viewer）可见、分页；viewer 可见但无任何操作按钮（前端面）。**冻结必含项②硬断言**：操作类型枚举必须覆盖"删除条目→恢复"闭环——editor 删除他人决策条目（裁决③合法）→ 留痕出现删除条目 → 管理员/editor 执行"恢复"（重推历史 rev）→ 留痕出现恢复行。⚠️ 契约核对警示见 §五-K1。
6. **转让、删除与离场**：管理员转让后旧管理员即时降档（旧凭证再写成员管理 → 403）；归档团队（裁决④）→ 新发布/编辑 → **409 team_archived**，成员仍可撤回既有副本（放行断言），保留只读；"删除团队"仅存在于治理口径（P2），P1 断言=归档非毁灭。成员被移出/账号停用（P0 status=disabled 级联）→ 成员身份即时失效（写 → 403/404），**其已发布副本保留**、历史留痕不删（契约 §2 信任语义）。
7. **冻结必含项①硬断言（409 冲突形态）**：团队副本快照 PUT 冲突响应必须含 `current_rev` + **最新全文快照**（UI §6 并排对比硬依赖）；缺字段/需二次请求拉全量作为唯一途径 → FAIL。协议其余（Idempotency-Key/If-Match-Rev/畸形头 400 invalid_header）沿用 P0 X 系断言至团队面。
8. **发布粒度与多发（裁决①）**：publish 支持纪要级与决策条目级两种 payload；一原件可发多团队，每团队独立副本行/独立 rev 时间线/独立撤回（按团队互不影响）；重复发布到已公开团队的行为不产生第二副本串线（前端置灰为第一道，后端幂等/冲突语义为第二道，实测报形态）。

### TA3 内容边界红线（B 域扩展，P0 W 系同尺）

- **录音与逐字转写永不进团队空间（裁决 5，结构性排除断言）**：团队副本 DTO 白名单不含 formal（逐字稿）与音频引用；构造含 formal/audio 字段的团队写请求 → **422 payload_not_allowed** + blob 快照 schema 禁字段兜底 + 客户端出境拦截双门禁三处分别断言；团队副本详情页无音频回放/逐字转写 Tab（前端面，抓包+DOM 双证）。
- **洞察板随副本（裁决⑤）**：副本携带 insights_html，团队面洞察 Tab 仅有内容时渲染；断言=发布含洞察的原件 → 副本含洞察、不含 formal；洞察字段中不得混入转写原文（抽样内容断言）。
- **发言人别名团队面只读（U4 拍板）**：副本携带映射后显示名文本；团队面无词表级编辑权（写 → 403/404，按端点是否存在实测定版）；声纹数据零出现在任何团队面响应（egress 白名单同尺扫描）。

### TA4 第五锁定面逐字断言（B5 基准，入 A 系矩阵——冻结令拍板一执行条款）

| 用例 ID | 断言 | 方法（与 P0 三行卡 B5 同法同级） |
|---|---|---|
| A4-L1 | 公开确认弹窗承诺块逐字＝「公开到团队的内容里不会包含录音音频和逐字转写，它们永远只保存在您的设备上。」一字不差（含"您"敬称、句号） | 构建产物 grep 逐字命中 + headless 渲染可见文本提取（剥离 script/style）双证 |
| A4-L2 | 单源渲染：该行仅由 lockedCopy.ts 单源常量引用，组件内无手抄字符串（禁手抄纪律沿用 P0） | 源码扫描：字面量在单源文件外出现 ≥2 处定义 = FAIL |
| A4-L3 | 防扩张：该逐字串挂点=公开确认弹窗一处；变更记录/团队首页等再现已入锁定文案 = FAIL（同义普通文案不在断言范围，不误杀） | DOM 出现点位枚举断言 |
| A4-L4 | 弹窗"不会出现（永远留在您的设备）：录音音频 · 逐字转写"区恒显示、不可勾选、无开关；术语默认不勾选（UI §4.2） | 渲染快照 + 交互断言 |

**六表面目检口径（W10 类运行时目检扩展，随冻结令终版计数）**：P0 五表面（登录/激活/同意卡/数据位置表/初始化向导）+ **公开确认弹窗 = 六表面**。第六表面为认证态+私有的会议+已建团队场景，执行载体随 P1-IMP FE WP-2（公开链）产出接入；P0 版三重证据法（产物逐字扫描 / headless DOM 可见文本 / 截图目视）原样沿用。

## 二、验收域 TB：企业资产层"只收集、不消费"口径

### TB1 前台零暴露断言（逐面扫描）

- **文案面**：企业形态全站 UI、i18n 键值、帮助文案出现"企业空间 / 企业资产 / 企业级空间 / 公司空间 / 公司层 / 已归档到公司"等把资产层当空间/入口呈现的字样 → FAIL（冻结令禁词表；"副本"同列 UI 文案禁词，用"团队看到的这份/您的原件"）。允许词"企业级资产"仅出现于说明性文案，不得为入口/导航/视图标题。
- **路由面**：`/enterprise*`、`/company*` 前端路由与 API 探测 → 404；构建产物无企业空间视图组件挂载。
- **接口面（Q2 裁决定稿：P1 资产层无任何访问界面，含实例管理员）**：契约无任何"列出/读取企业资产"端点——实例管理员亦 404（元数据计数除外，见 TA2-3）；前端侧加强证据链（采纳 FE 方案）：teams.ts 及全部前端源码 grep 无资产层读函数调用，"没有端点"升级为"前端连请求代码都不存在"。

### TB2 收集正确性断言（"自动成为企业级资产"的机器语义）

- **触发与幂等**：团队副本 decisions 任何新增/变更/删除 → 同事务 upsert enterprise_decision_assets，按 (source_task_id, decision_id) 唯一；并发/重放不产生重复行。
- **追溯三元组齐全**：每资产行含 source_rev、content_hash、collected_by/collected_at（"先收好、可追溯"即裁决 4 的全部兑现面）；snapshot_json 为决策文本态冻结快照，源副本后续编辑不回写已收集快照。
- **收集不改变可见性**：决策进资产层后，非本团队成员仍读不到（收集≠公开）——跨团队探测复用 TA2-1。
- **边界三断言**：私有空间未公开决策**不**进资产层（裁决①原文口径）；原件删除 → 资产行 status=stale 不删除（可追溯性核心承诺）；**撤回公开 → 资产行 status=withdrawn 保留（Q1 裁决定稿：保留标记、零界面）**，前台唯一呈现=变更记录"已撤回"条目（§7 留痕即状态，内容面消失）。

### TB3 迁移与团队词表回归（缺口A + §4，新增域）

- **ctx_assets expand-contract 重建（additive-only 首例外，产品已批）**：0002 迁移回归硬断言=**迁移前后个人词表内容 diff=∅**（逐 kind 逐条比对，含哈希）；迁移单事务、失败自动回滚实证（DevOps 演练环境承接，三件套纪律：备份前置+迁移事务化+回滚）；两段式回滚新口径（纯镜像回滚自 0002 作废）纳入升级回归剧本首跑。
- **团队词表 team-owned**：team_assets PRIMARY KEY(team_id,kind)——同一人建两团队词表互不串扰；editor+ 可写、viewer 写 → 403；留痕入 team_edit_audit；个人词表与团队词表在转写合成上的优先级为助手本地行为（裁决②并集、冲突个人为准），**不进契约承诺面**，本域不断言合成效果，只断言服务端两态数据互不污染。
