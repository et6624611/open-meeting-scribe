## 一、验收域 TA：团队维度越权矩阵（A 系扩展，team × 角色展开）

### TA1 矩阵维度

| 维度 | 枚举 |
|---|---|
| 资源 R | 团队实体（详情/成员列表）、团队空间内容（纪要/决策/笔记/术语的 读/列表/编辑/删除/公开撤回）、团队决策视图、成员管理（邀请/移除/改角色/转让管理员/删除团队）、企业资产层后台记录 |
| 角色 X | 非本团队任意成员（含同实例其他团队成员）、只读成员、可编辑成员、团队管理员、团队创建者（转让后）、**实例管理员（P0 admin）**、匿名/无令牌、篡改 team_id/role 的 JWT |
| 空间上下文 S | 私有空间内容、团队 A 内容（调用者为团队 B 成员）、已撤回公开的内容 |

### TA2 判定规则（P0 A 域同尺：统一 403/404、禁 5xx 枚举、无半泄漏）

1. **跨团队隔离**：团队 B 成员对团队 A 任何资源全操作 → 403/404；列表接口不得出现他团队条目的任何字段（含标题预览）；team_id 篡改 JWT 一律 401。
2. **三档权限逐格**：只读成员写操作（编辑/删除/公开/撤回/成员管理）→ 403；可编辑成员内容写 → 放行但**成员管理/删除团队/转让** → 403；团队管理员全权但**不得**改写成员的私有空间原件（公开=引用/副本语义，撤回权归内容 owner）。
3. **实例管理员边界延续（Q2 裁决同尺）**：P0 admin 对团队空间内容默认**不可读**（团队基于信任建立，管理员≠企业内容管理员）；除非产品另行裁决，用例按"不可读"单分支展开——与 P0"管理员看不到员工会议内容"一致，团队层不得成为企业面的旁路读通道。
4. **撤回语义**：owner 撤回公开后，团队全员读/写该条 → 403/404；私有原件不受影响；撤回留痕。
5. **修改留痕可证伪**：每次团队空间内容编辑产生审计行（actor、时间、字段 diff 指针）；留痕本身不可被可编辑成员删改；断言方式=编辑前后 diff 抓包 + 审计表行比对（egress_audit 同法）。
6. **转让与删除**：管理员转让后旧管理员降档即时生效（旧凭证再写 → 403）；删除团队=团队空间引用全清，成员私有原件零影响（删除的只是"公开关系"，不是内容本体——此条为裁决③信任语义的硬断言）。

### TA3 内容边界红线（B 域扩展，P0 W 系同尺）

- **录音与逐字转写永不进团队空间**：团队上下文快照 DTO 白名单不含音频字节/转写全文字段（转写=formal 字段，按裁决永不公开——团队可见的只有纪要/决策/笔记/术语）；构造含 formal/audio 的团队写请求 → 422 拒收 + 客户端出境拦截双门禁；抓包断言与 B5 同意卡口径同步扩一行团队承诺文案（UI 规格定稿后逐字对齐，方法同 P0 B5）。
  - ⚠️ 待产品/UI 确认：团队空间承诺文案是否入锁定表面集（建议入，第五处渲染面），定稿前该断言按"无承诺文案则不出现相反断言"最低标准执行。

## 二、验收域 TB：企业资产层"只收集、不消费"口径

### TB1 前台零暴露断言（用户明示的边界，逐面扫描）

- **文案面**：全站（企业形态）任何 UI 表面、i18n 键值、帮助文案出现"企业空间 / 企业级空间 / 公司空间"等把资产层当空间/入口呈现的字样 → **FAIL**（项目方裁决③：不放出公司级概念）。允许词："企业级资产"仅可出现在**说明性文案**（如设置页一句话解释决策去向），不得作为可点击入口、导航项、视图标题。
- **路由面**：GET/探测 `/enterprise*`、`/company*` 类前端路由与 API 端点 → 404/不存在；企业形态构建产物 grep 无企业空间视图组件挂载。
- **接口面**：契约不得暴露"列出全部企业资产"的读端点给普通成员（收集=后台行为）；若后端为追溯需要设内部端点，鉴权口径单列用例（仅实例管理员可访问且仅元数据——该权限归属**待产品裁决**，见 §三-Q2）。

### TB2 收集正确性断言（"自动成为企业级资产"的机器语义）

- 团队空间内每条决策的产生/变更/删除，企业资产层记录同步（数量与内容一致，追溯钩子=决策 id+team_id+版本指针，后端契约定义后展开）；
- **收集不改变可见性**：决策进入资产层后，非本团队成员仍读不到（收集≠公开）——跨团队探测断言复用 TA2-1；
- 私有空间未公开的决策**不**进资产层（资产化只发生在团队空间内容的决策上，裁决①原文"所有属于团队内容当中的决策"）；
- 撤回公开 → 资产层对应记录处置（保留追溯 or 撤销）→ **待裁决**（见 §三-Q1），当前按"撤回后资产层不可被任何前台读到"最低标准断言。
