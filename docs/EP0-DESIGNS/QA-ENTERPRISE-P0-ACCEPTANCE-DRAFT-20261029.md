## 0. 术语与判定口径

- **出境**：数据离开员工本机、发往企业服务器或其他网络对端。企业版内"服务器"是授权对端，"其他对端"默认未授权。
- **定稿文本**：任务状态进入定稿后的转写/纪要/决策流/笔记/术语内容。中间态（实时转写候选段、未保存草稿）**已裁决一律不出本机**（产品裁决 Q4，cmsg_01m63frf0zk4ap0966st6t9hft）；后端 WS schema 若承载非定稿文本即判 B 域 FAIL。
- **证据形态**：每条用例必须产出 ①请求/响应记录（代理抓包导出）②服务端落库抽查 ③审计日志行。口头"应该没问题"不作为通过信号。

## 1. 验收域 A：跨用户越权测试框架

### A1 测试矩阵（资源 × 操作 × 令牌形态）

| 维度 | 枚举 |
|---|---|
| 资源 R | 任务(task)、纪要/笔记(note)、决策流(decision)、热词/术语(hotword/glossary)、用户设置(settings)、导出件(export)、实时通道(WS realtime)、录音控制面指令(record start/stop——本地控制面，见 A3) |
| 操作 O | 读单条 / 列表 / 更新 / 删除 / 导出 / WS 订阅 / 控制指令 |
| 令牌 X | 无令牌、他人有效 JWT、本人过期 JWT、已注销用户 JWT、管理员 JWT（测 A2 边界）、篡改 user_id 的 JWT |

**用例总数 = R×O×X 有效组合（契约定稿后展开为逐条用例清单）。**

### A2 判定规则

- 访问他人资源：一律 403 或 404，**禁止 5xx**（5xx 与 403 可区分即资源枚举泄露，判 FAIL）。
- 列表接口：仅返回本人可见集，不得出现"字段可见但点开 403"的半泄漏。
- WS realtime：订阅他人 task_id 必须拒绝，且服务端不得推送他人增量（抓 WS 帧验证）。
- 管理员令牌（Q2 已裁决单分支）：P0 管理员**不可读**任何员工业务内容——管理 JWT 访问任务/纪要/决策/热词/导出/WS 等业务端点一律预期 403/404；"可读+审计"分支已从用例矩阵删除，P0 若实现可读通道本身即 FAIL。
- 已停用/注销用户（Q3 已裁决最小口径）：停用即刻收回登录与同步权——其 JWT 一切端点 401、离线队列同步通道拒绝；其已存企业服务器的定稿文字**保留归属企业**，仅管理台"整包删除"为 P0 唯一删除路径（该操作本身进 A1 矩阵鉴权用例）；无自动到期删除。

### A3 控制面特例（录音 start/stop）

录音控制走本机 localhost，不经过服务端。越权定义转化为：服务端**不得**接受任何能远程操控他人本机录音的指令或状态订阅。若后端契约提供"设备绑定"通道，此条转为对等设备鉴权用例。

### A4 存量迁移专项（裁决④）

- 以 13373013103 账号登录：全部存量任务/笔记/热词可见、可用、可导出。
- 以其他新建账号登录：上述内容在任何接口、任何 UI 检索路径**零可见**。
- 迁移前后存量数据内容 diff = ∅（允许 schema 级新增字段，不允许内容丢失/截断）；迁移失败可回滚且回滚后旧版应用仍可读写原目录。

### A5 出场 gate

矩阵 100% 执行、FAIL 清零或降级为已裁决接受的书面例外，否则 P0 不得出验收。

## 2. 验收域 B：数据出境白名单（可抓包验证）

### B1 企业版 P0 默认白名单（授权对端枚举）

| # | 对端 | 允许内容 | 验证方式 |
|---|---|---|---|
| W1 | 企业服务器 origin（内网部署地址） | 定稿文本五类（转写/纪要/决策流/笔记/术语）、账号与权限元数据、任务状态元数据、（如裁决允许）脱敏审计日志 | 正向抓包 + 落库抽查 |
| W2 | localhost / 本机引擎 | 音频流、实时转写、声纹注册与匹配、未定稿草稿 | 本机侧断言"无发往 W1 的同内容副本" |
| W3 | （条件项）LLM/搜索等云对端 | 仅当产品裁决 Q1 允许云端 AI 时按域名逐个加白 | 见 §4-Q1 |

### B2 禁止出境清单（红线，命中任一即 P0 FAIL）

- L1 音频：任何格式音频字节（含分片、临时文件上传、WS binary 帧）。
- L2 声纹：embedding 向量、注册表音频特征（服务端只允许 speaker 别名映射文本）。
- L3 凭据：API Key/token 明文（含请求头之外的日志、报错回显、任务 payload）。
- L4 非白名单对端：DashScope（dashscope.aliyuncs.com）、GitHub OAuth/api.github.com、ModelScope、Brave Search、版本检查/引擎下载 release 域名、SMS 代理——以上均为现仓库实测存在的出网面（asr-proxy/server.py:52、core/auth.py:48-51、core/model_downloader.py:41、core/agent_tools/impl.py:345、core/version_check.py、core/engine_installer.py:36、core/sms.py）。企业版 P0 下这些必须**默认关闭或不可达**，除非 W3 裁决放行。

### B3 内容级断言（不止看域名，要看字节）

- 对 W1 全部请求体做敏感模式扫描：音频 magic bytes、embedding 浮点数组特征、`sk-` 型 key 模式、base64 大块二进制 → 零命中。
- 服务端存储抽查：SQLite/文件树内不含音频路径可达的下载代理、不含 embedding 列有值、不含明文凭据。
- 离线队列重传：断网→恢复后重传，**同一定稿不产生重复记录**（幂等键验证；契约细节待后端，框架先立：at-least-once 投递 + 服务端去重断言）。

### B4 数据流向声明一致性（企业版 AC-5 姊妹项）

企业版发布材料 / SECURITY.md 企业版章节 / UI"数据位置"指示三处声明，与 B1 实测抓包结果逐条一致。不一致判 FAIL（个人版此条已有先例纪律）。

### B5 同意卡三行定稿文案 = 对外承诺 = 抓包事实（产品经理定稿，cmsg_01m63fn448vz5fta7ahrggq9rk）

定稿文案（措辞即承诺，验收按逐字比对，任一字符差异判 FAIL）：

> 你的会议录音和音频只保存在这台电脑上，不会离开本机。
> 会议定稿后的文字内容（转写文本、纪要、决策流、笔记、术语）会保存到公司服务器，方便你在任何设备上查看。
> 你的声纹信息和 API 密钥永远不上传。

**逐字一致的三处 UI 表面**：①上传知情同意卡 ②Settings「数据位置」三行表 ③登录页隐私说明。

**行 → 抓包/落库断言映射**：

| 承诺行 | 断言 | 挂钩条款 |
|---|---|---|
| 第 1 行（音频不出本机） | 全场景抓包无任何音频字节发往 W1 以外或对端；服务端存储无音频文件及可下载代理 | L1、B3 |
| 第 2 行（仅定稿五类文字上公司服务器 + 跨设备可查看） | W1 请求体内容类型白名单=转写/纪要/决策流/笔记/术语（中间态草稿不在其中，Q4 待最终确认）；同账号异设备登录可读全部定稿 | W1、B3、§6-U3 |
| 第 3 行（声纹与密钥永不上传） | 全流量零 embedding 向量、零凭据明文（含日志/报错回显）；服务端落库抽查同判 | L2、L3、B3 |

文案与 B1/B2 枚举存在任何一处"UI 说了、抓包没发生"或"抓包发生、UI 没说"的双向失配，均判 P0 FAIL。

|---|---|---|
| C1 | 零新增默认出网点 | 升级后安装包的抓包画像与基线版本一致：本地引擎模式下除 localhost（+模型权重首次下载白名单）外零出网。diff 非空即 FAIL |
| C2 | 本地数据目录不被污染 | 升级前后 `data/` 树：文件级清单 diff 仅允许新增（schema 迁移产物），禁止删除/改名/内容截断；升级后旧版本可回滚继续读写 |
