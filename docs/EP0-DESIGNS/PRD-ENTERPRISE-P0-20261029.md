## 1. 一句话定位

企业版 = 把现在"装在自己电脑上的会议记录助手"，变成"装在贵公司服务器上、全公司同事一起用的会议上下文系统"。同一套代码、两种装法（双产品线）；个人版保持"数据不出设备"承诺不变，企业版立"数据只出到贵公司服务器"新承诺。

## 2. 目标用户与场景

- 管理员（通常是公司 IT 或负责人）：在一台内网服务器上跑一键安装包，开通服务，建同事的账号，发邀请码。
- 员工：浏览器打开公司网址登录，查看/编辑自己的会议纪要、决策流、笔记、热词、发言人；电脑上装"本地录音助手"后照常本地录音，会议定稿文字自动同步到公司服务器，换台设备也能接着看。

## 3. P0 功能清单（用户向）

| # | 功能 | 用户看到什么 |
|---|------|-------------|
| F1 | 管理员开通服务 | 4 步初始化向导：设管理员账号（默认认领手机账号 13373013103 与存量数据）→ 确认访问地址 → 复述数据承诺 → 发出第一张邀请码 |
| F2 | 账号体系 | 管理员建占位账号+生成邀请码；员工凭码自助设密码（管理员不经手密码）；无短信、无第三方登录；管理台保留重置密码兜底 |
| F3 | 员工登录与个人空间 | 账号密码登录；现有工作台整体成为"我的空间"；登出彻底清空本机该用户缓存 |
| F4 | 本地录音助手 | 浏览器引导下载（下载源=公司服务器离线包，零外网依赖）；设备配对后可录音；无助手设备只能看/编辑文字（P0 默认形态） |
| F5 | 定稿文字同步 | 只有定稿文字上服务器；"待同步到公司服务器"状态提示；离线不丢内容，恢复后续传幂等 |
| F6 | 数据透明 | 首次生成纪要弹一次知情同意卡（三行文案见 §5），此后每张纪要卡常驻"数据位置徽标"；Settings 有「本机录音助手」「数据位置」分区 |
| F7 | 用户隔离 | 任何同事（含管理员）都看不到你的会议内容；每人数据只在自己账号下 |
| F8 | 服务启停 | 管理台概览有企业服务大开关；关闭后已登录者看"服务已暂停，仅可查看已同步内容"横幅、写操作禁用；新登录在登录页拦截 |
| F9 | 备份与升级 | 每日自动备份保留 14 天（只在本企业服务器）；升级强制先备份、失败自动回滚 |
| F10 | 加密（推荐非强制） | 出厂 HTTP 可用；管理台常驻"一键开启加密"（内置 CA），向导内显著推荐 |

## 4. 明确不做（非目标，防止范围蔓延）

- 团队/企业共享上下文、内容晋升（P1/P2）；管理员查看员工内容；Web 端录音；移动端小屏适配（P1 候选）；云端 AI 默认开启；自动到期删除员工数据；Windows Server 验收承诺（出文档不出口径）。
- 用户删除回收站：P0 采用软删 30 天默认（产品经理已确认），决策状态字典管理台页面排 P1。

## 5. 对外承诺（措辞即验收基准，QA B5 双向失配判 FAIL）

知情同意卡 / 数据位置三行表 / 登录页隐私说明，三处逐字一致：

> 你的会议录音和音频只保存在这台电脑上，不会离开本机。
> 会议定稿后的文字内容（转写文本、纪要、决策流、笔记、术语）会保存到公司服务器，方便你在任何设备上查看。
> 你的声纹信息和 API 密钥永远不上传。

企业版数据治理承诺：服务器在贵公司内网；默认零出网（唯一例外=管理员显式开启 AI 后配置的域名）；备份只留本机 14 天、永不上传外部云；文案统一说"公司服务器"，禁"云端"字样；个人版不继承以上表述、继续说"数据不出设备"。

## 6. 验收出场门禁（QA 标准 v1.0 为操作细则）

1. 跨用户越权矩阵 100% 执行（含管理员不可读断言）；
2. 数据出境白名单抓包=枚举清单（默认仅企业服务器 origin+localhost）；
3. 存量迁移对账：13373013103 收存量、其他账号零可见、diff=∅ 可回滚；
4. 个人版回归门禁：零新增默认出网点、本地数据目录不污染、无企业字段残留；
5. CA/加密不作为出场 gate（两口径分别验收）。

## 7. 向项目方明示的待确认体验点（不阻塞今晚实施，按默认值先行）

1. 会议文字默认不发给任何外部 AI 公司（AI 纪要功能默认关闭）——如需使用由管理员逐个开启。默认执行。
2. 完全无外网的隔离内网 → 离线 tar 包已按必选交付，天然覆盖。
3. 同事用手机/无助手电脑 → 只能看和编辑文字、不能录音，为 P0 默认形态。
4. 老用户升级 → 数据归入 13373013103 账号，首登一张"老数据已归入你的账号"告知卡，不需要任何确认动作。
