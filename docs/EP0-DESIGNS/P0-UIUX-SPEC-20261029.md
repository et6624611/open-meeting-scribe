## 0. P0 用户心智模型（一句话）

企业版 P0 = 公司里装了一台"会议文字柜"（服务器），每位员工有自己的账号抽屉；
录音仍然发生在员工自己这台机器上，只有写完的文字放进文字柜。
界面上所有设计都要让用户随时能回答两个问题：**"我的录音在哪？"**（本地）和**"我的文字在哪？"**（公司服务器）。

全线文案规则（产品经理定为全线规则）：
- 统一说"公司服务器"，禁止出现"云端"字样。
- 不复用个人版"联网/离线"词表描述上下文存储。
- 企业版隐藏 SMS/GitHub 等个人版登录入口与云引擎文案（个人版零变化）。

## 1. 登录 / 用户空间（邀请码主路径）

### 员工看到什么
1. 打开公司给的网址 → **登录页**：账号 + 密码。企业版登录页只有账号密码一种入口。
2. **接受邀请流程**（首次入伙）：员工从管理员处拿到邀请码 → 登录页下方"接受邀请"入口 → 输入邀请码 + 设置自己的密码 → 完成，全程管理员不经手任何密码。
3. 登录成功 → 进入 **"我的空间"**：就是现在软件里的熟悉界面（录音、纪要库、项目、决策流、热词、发言人、设置），全部内容默认只有本人可见。
4. 顶栏右侧固定出现 **头像菜单**：设置、"我的数据在哪"、退出登录；管理员额外多一项"进入管理台"。

### 界面规则
- 未登录访问任何功能 URL → 统一重定向登录页，不弹空白页或报错。
- 会话过期（掉线）→ 顶部提示条"登录已过期，请重新登录"，正在编辑的内容本地暂存不丢。
- 登录页隐私说明：使用 §7 锁定三行原文（见下）。
- 登出必须清空该用户命名空间下全部本地缓存（前端档位①，防上一用户状态泄漏——走查硬项）。

### 企业服务暂停时（裁决④）
- 已登录会话不踢出：页面顶部常驻横幅"企业服务已暂停，仅可查看已同步内容"，全部写操作（编辑/新增/同步）禁用。
- 新登录在登录页拦截："企业服务已暂停，请联系管理员"。
- 两端都要让员工明白是管理员关的服务，不是软件坏了。

## 2. 本地数据目录设置（用户端 Settings）

前提事实：浏览器本身不录音，录音由本机的"录音助手"（本地引擎）完成。**无助手设备（同事电脑/手机浏览器）"只能看和编辑文字、不能录音"即企业版 P0 默认形态**；移动小屏适配不进 P0（P1 候选）。

### 分区 A：「本机录音助手」
- 状态卡：本机是否已连接录音助手（绿/灰）。
  - 已连接：显示版本号、数据目录路径、剩余磁盘空间。
  - 未连接：显示引导页——"这台电脑还没有安装录音助手"，提供**公司服务器内下载**（离线包，零外网依赖）+ 配对码引导流程；同时明确"不安装也可以：你可以正常查看和编辑已有会议文字，只是不能在这台电脑上新开录音"。
- 操作：修改本地数据目录（含"移动已有文件"二次确认）、查看用量、清理。

### 分区 B：「数据位置」（P0 隐私指示核心）
静态说明页：图标化三行表 + **§7 锁定三行原文**。

| 内容 | 存放位置 |
| --- | --- |
| 会议录音音频 | 只在你这台电脑 |
| 密钥、声纹识别信息 | 只在你这台电脑 |
| 会议文字（转写、纪要、决策流、笔记、术语） | 公司服务器 |

- 该分区只读、无开关（P0 上云行为不可关闭，与裁决一致）。

### AI 助手未开启态（裁决 QA Q1：默认零出网）
- 企业版默认关闭云端 AI 生成纪要。相关按钮显示禁用态 + 文案"AI 助手未开启，联系管理员"。
- 管理员在管理台显式开启后，员工端按钮恢复可用（开启动作与逐域白名单在管理台 AI 助手设置区完成）。

## 3. 上传知情同意流程（粒度已裁决）

### 首次触发
员工第一次完成会议并生成纪要时，弹一次 **知情同意卡**（仅首次，可在 Settings「数据位置」回看）：
- 正文 = §7 锁定三行原文，一字不改。
- 按钮：「知道了，继续」/「查看数据位置」。
- 不做每会确认，不做额外全局开关（P0 本无上传选择权）。
- 此后每一张纪要卡片上常驻 **数据位置徽标**（见 §5），作为持续告知。

### 断网/重传的用户感知
离线时文字暂存在本机待传队列，界面显示"X 条文字待同步"（数据源：接口 sync_status=pending），恢复后自动重传；不报错、不丢字。状态文案用"待同步到公司服务器"，不用"上传失败"红色告警；sync_status=error 时才出现可重试提示。

## 4. 管理台 MVP 信息架构（管理员看到什么）

### 入口与边界
- 管理台是**独立网址**（http(s)://公司服务器地址/admin），与员工界面完全分离；员工端不出现任何管理功能入口。
- 管理员本人用会议功能时就是普通员工身份，两边界面不混排。
- 首个管理员来自 DevOps 的"管理员初始化向导"（向导只产首个管理员；日常用户管理全在 /admin）。
- **管理台不提供任何查看员工会议内容的入口**（裁决 QA Q2：默认不可见，可读通道 P0 不做）。

### 页面结构（P0 共 3 页 + 1 引导）
1. **概览**：服务运行状态、用户数、磁盘用量、最近同步动态。
   - 顶部大开关：企业服务启用/停用。停用效果的管理员侧说明定稿文案（W2-03）："停用后，已登录的员工仍可查看已同步内容，但不能编辑；新的登录将被拦截，重新启用服务后恢复。"员工端表现见 §1。
   - **加密状态卡（W2-01 修订口径）**：本页常驻 = 当前加密状态 + 开启收益一句话 + 可直接复制的配置指引（指向 DevOps 向导/文档命令）。"一键运行时切换"降为 DevOps 向导路径（TLS 需 compose 重配）；原则不变：管理员在管理台随时看得见、想得起开加密。
   - **AI 出网区（W2-02 定稿措辞）**：默认关闭；开启需显式操作并逐域加白名单。凭据字段名**"云端 AI 服务凭据"**（管理台不得再出现"API 密钥"独立指代），该区下方说明行逐字为："仅用于 AI 出网功能，存放于公司服务器，与员工本机的 API 密钥无关。"员工侧未开启态文案"AI 助手未开启，联系管理员"。
2. **用户管理**：
   - 列表：姓名、账号、状态（正常/已停用/待接受邀请）、创建时间、**上次使用**（真语义 last_used_at，W2-04：null 显示"未使用过"；"最近更新"仅保留为排序列）。
   - 操作：新建用户 = 填姓名+账号生成**占位账号+邀请码**（管理员复制/发送邀请码，不经手密码）、重置密码（作废旧会话+重发邀请码，兜底路径）、停用/启用。
   - 停用即刻收回登录与同步权；其定稿文字保留在企业服务器上（归属企业），列表行操作提供"**删除该用户全部服务端数据**"（整包删除，破坏性操作，二次确认 + 输入账号名确认）。
   - 邀请码过期未使用的占位账号可作废重发。
3. **数据与备份**（只读为主）：服务器文字数据总览、指向 DevOps 备份流程的说明卡（含对外承诺口径："企业数据备份只保留在企业自己的服务器上、自动保留 14 天、永不上传外部云"）。P0 不做界面化备份操作。
4. **老数据归属说明页**（一次性）：见 §6。

### 管理台不承担（P0 明确不做）
审计日志界面、员工内容查看通道、团队/企业上下文管理、配额管理、界面化备份——留给 P1/P2。

## 5. 上下文可见性徽标（P0 仅样式预留）

统一徽标组件，三态定义一次到位，P0 只渲染"个人"：
- **个人**（P0 唯一实际态）：小锁图标 + "仅你可见"，出现在纪要/决策/项目卡片与详情页。
- **团队**（P1）/ **企业**（P2）：图标与样式预留、不出现在界面；接口固定返回 visibility="personal"（后端契约点）。

规则：徽标是**数据属性**的展示，不是页面分类导航；P0 不出现"团队/企业"任何文字，防止用户误以为已有共享功能。

## 6. 存量数据迁移的用户体验（账号 13373013103）

- 该手机号账号首次登录企业版时，显示一次性卡片："检测到你过去在这台电脑上的会议资料，已归入你的账号。"列数量摘要（N 场会议、M 条纪要），并重申"音频仍留在原来那台电脑上"。
- **告知即过**（裁决③）：只有一个「知道了」按钮，无确认归属动作、无后端用户回执。
- 其他员工账号首次登录：空状态页"还没有会议，点击开始记录第一场会议"。
- 存量热词/术语仅该账号可见，其他用户默认不可见（裁决 QA Q5）。

## 7. 锁定文案块（QA B5 断言基准，三处 UI 逐字一致）

**语言口径（产品经理拍板，cmsg_01m63gms3vcn2habq9phfwbvjv，2026-10-29）**：锁定承诺块**仅中文逐字呈现，P0 不参与 i18n**。承诺措辞是数据治理声明而非界面文案，英文界面下该块保持中文；P0 所有文档不承诺英文版。"企业版多语言官方译法+译本纳入 B5 断言"记入 P1 需求候补，届时由产品经理与 QA 共同定义。

以下三行为**定稿对外承诺文案**（产品经理定稿，cmsg_01m63fn448vz5fta7ahrggq9rk 第 5 条），在以下三处 UI 表面逐字一致出现，任一字符差异判 FAIL：
1. 上传知情同意卡正文（§3）
2. Settings「数据位置」三行表说明文案（§2 分区 B）
3. 登录页隐私说明（§1）

> 你的会议录音和音频只保存在这台电脑上，不会离开本机。
> 会议定稿后的文字内容（转写文本、纪要、决策流、笔记、术语）会保存到公司服务器，方便你在任何设备上查看。
> 你的声纹信息和 API 密钥永远不上传。

辅助口径（允许场景内出现，非锁定块；W2 裁决新增两条入 QA W10 词表门禁范围）：
- 服务暂停横幅："企业服务已暂停，仅可查看已同步内容"；登录拦截："企业服务已暂停，请联系管理员"。
- 管理台停用效果说明："停用后，已登录的员工仍可查看已同步内容，但不能编辑；新的登录将被拦截，重新启用服务后恢复。"
- 管理台 AI 出网区说明行："仅用于 AI 出网功能，存放于公司服务器，与员工本机的 API 密钥无关。"
- AI 未开启："AI 助手未开启，联系管理员"。
- 待同步："待同步到公司服务器"。
- 词表门禁补充（产品经理 W2-02 令）：除四处锁定文案表面外，全站任何"上传/保存密钥"类 UI 表述不得与承诺第三行构成同词反向断言。
