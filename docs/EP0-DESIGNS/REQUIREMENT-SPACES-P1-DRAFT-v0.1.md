## 一、您描述的空间，用产品语言复述一遍（请确认我理解对不对）

您获得账号后，系统里有三个"空间"，像一栋办公楼的三个楼层：

| | 私有空间 | 团队空间 | 企业空间 |
|---|---|---|---|
| 放什么 | 您的一切会议内容（默认都在这里） | 您主动"公开给团队"的内容 | 全公司层面的内容 |
| 谁能看 | 只有您 | 团队所有同事 | 全体员工 |
| 公开的内容范围 | — | **除录音音频和逐字转写以外**：纪要、决策、笔记、术语等 | **只有"决策"** |
| 谁能修改 | 您 | 内容原作者（同事可看可引用） | 内容原作者（管理员可治理） |
| 录音/音频在哪 | 只在您的电脑上 | **永不进入团队空间**（按您的边界） | **永不进入企业空间** |

一句话核对：**您的会议默认只有您自己看得见；您选择哪些纪要和决策公开给团队、公开给公司；录音和逐字稿永远留在您的电脑上，不进任何共享楼层。**

## 二、内容怎么"上楼"（公开的动作设计）

- 每份纪要/决策上有一个"公开"按钮：选择公开到【团队】或【公司】，随时可撤回。
- 公开的是"这一份内容的副本进入那个空间"，您私有空间里的原件不受影响。
- 决策比较特殊（您的企业空间只放决策）：会议里产生的每条决策，可以单独选择"公开到公司"——因为一条决策常常比整篇纪要更值得让全公司看到。
- 界面延续现在已上线的"个人·仅你可见"小锁徽标：公开后徽标变成"团队"或"公司"，一眼可辨。

## 三、这次升级会一并解决的问题（您上次反馈的"菜单变少"）

- "项目"面板回到左侧菜单：项目就是"团队空间"的一种组织方式（把相关的会议纪要/决策归到一个项目里共同管理）。
- "决策面板"回来：展示团队/公司空间里公开的全部决策（正是企业空间"仅决策公开"的落地界面）。
- 热词/发言人：从"只能看"升级为"团队可共享一份团队词表"（谁的术语准，公开后全团队转写都受益）。

## 四、四个请您拍板的问题（勾选即可，都给了我们的建议）

1. **决策进企业空间的方式**：A. 每条决策由本人或管理员"主动公开到公司"（建议选 A：防止某条内部决策被同事误看到）；B. 所有决策自动进企业空间。
2. **团队空间里谁能改内容**：A. 只有原作者能改，别人只能看（建议选 A：简单可靠）；B. 团队成员都能改（像共享文档）。
3. **"团队"的大小**：A. 第一版全公司就是一个团队，不分区（建议选 A：先跑通，部门分组以后加）；B. 第一版就要按部门分多个团队。
4. **企业空间谁能看**：A. 全体员工（建议选 A："决策透明"本来就是您要的价值）；B. 只有管理层。

## 五、排期与边界的实话

- 这个方案是原计划的 P1 主体，您拍板第四节四个选项后我们拆单开工；预估工作量比 P0 大（涉及权限体系），完成后会像这次一样给您可体验的版本。
- 已上线的 P0 不受影响：现在存进服务器的内容全部还在您的私有空间，一个字节都不会自动公开——"公开"永远是您的主动动作。
- 数据存放原则不变且被您的边界强化：录音永远在您电脑；服务器只存您定稿的文字；团队/企业空间只是"文字内容的可见范围"，不是新的存储地点。
