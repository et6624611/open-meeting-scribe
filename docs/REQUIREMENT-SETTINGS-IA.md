# REQ-SETTINGS-IA · 设置信息架构重构

## 1. 背景与问题（证据链见原型 ①② 页，全部经代码核实）

一个逻辑状态「接入方式 access_mode」存在 **四个写入口**：接入方式卡（自动保存）、「服务」页（显式保存）、「计算引擎」页 dropdown（反向同步 derive_access_mode）、账户开关 prefer_subscription（路由输入参与模式推导）。后果：

1. **双写保存语义相反**（AccessModeCards.vue:255-261 即改即落盘 vs SettingsView.vue:1513-1523 显式保存，共享同一 reactive settings，:127 注释自认互为可见）——未保存草稿冒充已生效值；「清空 Key」一次点击即落盘无确认。
2. **隐私承诺与实现无绑定**：「零出网」写死 i18n settings.json:167 不读字段；voiceprint.provider 在离线档是被 embedding_provider.py:518-530 短路忽略的**死字段**；而联网 proxy 档云端声纹**确实出网**（i18n:275），且运行时默认值即 provider=cloud。
3. **同一状态三套词汇**（卡片/引擎下拉/矩阵列头互不相认）+ 幽灵枚举 engine_mode_cloud。
4. **prefer_subscription 静默改写账单**：自带 Key 用户实际走平台计费（routing.py:148-150 route_override），界面不说。
5. 反向同步（routers/settings.py:378-381）使编辑 ASR/engine 字段可静默改变用户选过的接入模式。

## 2. 目标与用户价值

- 用户用**一张决策卡**说清「算力归谁」，用**逐能力详情**说清「每个能力花谁的钱、数据出不出网」；界面所有承诺由实现派生，不再出现写了不算的字段。
- 出口判据：**同一逻辑状态全产品唯一写入口；每一条隐私/计费文案要么派生自字段、要么删除。**

## 3. 范围（五刀）与非目标

### 3.1 决策层重构（原型第 1 刀）
- 三卡收敛为两卡：**离线模式 / 联网模式**（Q1 已裁）。联网卡副标题用判据措辞「至少一项能力使用云端算力 · 计费来源逐能力在详情选择」（裁决-3：允许 LLM=本机端点例外，例外不上顶层卡）。
- 详情层六卡：账户·套餐 / LLM·算力来源 / ASR·算力来源 / 引擎·本地组件 / CLI 引擎 / 使用面回显；详情层与决策层视觉两层分离（缩进+引用轨），离线态 LLM/ASR 卡整卡「🔒 本机接管」置灰。
- access_mode=null 未选态：强引导条「还需一步：先选一个接入方式」，联网卡标注登录条件。
- 切换后果预览弹窗：字段级 diff（字段/现值/将写入）+ 进程动作 + 计费与出网三段；确认按钮文案具体化；联网→离线方向加红色「将打断进行中的转写」风险条目并要求显式勾选知晓（裁决-2）。
- **事务语义（裁决-1）**：切换全量回滚——引擎启动失败等任一环节失败，access_mode/engine.mode/asr.mode 均不写入，界面明示「未生效，已保持原模式」。

### 3.2 单向数据流 + 保存语义统一（第 2 刀）
- 接入方式唯一写入口 = 决策卡；「服务」页 = 参数唯一编辑面（显式保存）；引擎页 dropdown（SettingsView.vue:340-344）改只读徽章；卡片内联自动保存面板废除（AccessModeCards.vue:128-147）。
- derive_access_mode 反向同步（routers/settings.py:378-381）降级为旧客户端兼容窗口（带日落期限），新 UI 写路径不再依赖。

### 3.3 词汇收敛（第 3 刀，裁决-4 定五词）
- 用户词表：**离线 / 联网 / 体验配额 / 自带 Key / 本机端点**（末词仅 LLM 详情层）。托管、体验代理、自持 Key、自接端点、平台代理全量清退；proxy/cloud/direct/engine_mode_* 仅专家注释。幽灵枚举 engine_mode_cloud 随删除。流向矩阵搬入接入方式页、四列（离线/体验配额/自带 Key/本机端点）、按能力逐行高亮、单元格带「出网 ↑ / 零出网」双通道徽章。GLOSSARY.md 同步：「托管」留历史映射注记。

### 3.4 声纹云端下架（第 4 刀，2026-09-26 裁决① 落地）
- 删除：voiceprint.provider 字段、cloud_base_url/cloud_api_key、「服务」页声纹区块（SettingsView.vue:280-300）、卡片折叠区 provider 选择器（AccessModeCards.vue:69-85）、hosted 档云端声纹链路（embedding_provider.py:533-549 云分支、i18n:275 文案）。
- 「零出网」从静态文案改为结构性为真（无云端代码路径可走）。
- ⚠ **注册表迁移评估需 Dev 确认**（评审附录 B 末行）：确认说话人注册表落盘路径与云端特征兼容性后，本单才可写「无用户数据迁移」；当前按「待 Dev 核实」挂起。
- 连带：Q5 知会 QA（OBS-01 云端声纹重部署预案取消、QA-R2 启动门相应项移除）；Q6 知会 DevOps（WP-G 冻结包删除云端声纹客户端代码路径）。

### 3.5 prefer_subscription → 账户默认勾选（第 5 刀，2026-09-26 裁决② 落地）
- 体验/托管不再独立成卡：随账户登录成为 LLM/ASR 详情中可选来源；账户卡「优先使用体验配额」勾选 = 详情**默认值**来源。
- 三态徽章：默认生效（账户）/ 已覆盖（本能力，**持久化，不被下次登录或勾选改回**）/ 未设置；离线态第四形态「本机接管」；离线态下勾选置灰并明示「暂不生效」（不弹成功反馈）。
- route_override 静默语义消灭。配额耗尽提示按 **Q3 三级方案**：L1 能力行内常驻（≥4.5:1 amber + 行内 CTA）/ L2 页面级 amber 横幅（不用红，可折叠为历史行）/ L3 联网卡角标「N 项能力已自动改用」；10 分钟预警阈值；文案用「自动改用」，界面禁用「降级/兜底/fallback」；每次自动改用落本地事件记录（关联账单争议）。
- Q4 计量口径未终裁：界面两条能力卡账单行标注「共用同一额度池」兜底，后端分池与否转后端择期评审。

## 4. 存量迁移（A2 兼容窗口内双写旧字段）

| 存量 access_mode | 迁移为 | 投影不变量 |
|---|---|---|
| local | 离线模式 | engine.mode=local |
| hosted | 联网 + LLM/ASR 来源=体验 + 勾选开 | engine.mode=proxy |
| byok | 联网 + 来源=自带 Key + 勾选关 | engine.mode=direct |

A1 裁决（direct+订阅开=托管）随本单**废止**；混配存量按详情层逐能力读实际值，冲突明示不静默。

## 5. 验收标准（AC）

1. 设置内任一字段**有且仅有一个写入口**；grep 全前端不再存在 AccessModeCards 内联保存路径与引擎页可写 dropdown。
2. 决策卡切换必经后果预览；断网/模型缺失模拟下切换失败 → settings.json 逐字段比对**零写入**（全量回滚自动化用例）。
3. 「零出网」「体验配额将消耗分钟数」两类承诺文案 100% 由字段派生渲染；voiceprint.provider 字段在 schema/UI/后端三处不存在。
4. 五词表 lint：用户可见文案 grep 不含 托管/体验代理/自持 Key/自接端点/平台代理/降级；矩阵四列高亮随逐能力来源正确（联网+LLM=本机端点时 LLM 上下文行高亮在「本机端点」列且标零出网）。
5. 勾选「优先使用体验」→ 两条详情默认生效并出徽章；逐能力覆盖后重新登录/改勾选，覆盖值不回退；离线态勾选置灰且不生效。
6. 配额=0 演示：L1/L2/L3 三层齐现、无 toast、事件记录落盘可查；恢复额度后横幅转灰。
7. 无障碍（裁决-5 产品级规则）：注释层/状态文字 ≥12px 且对比度 ≥4.5:1（含本单全部新增组件）。
8. 回归：既有 pytest 全量绿；迁移映射表单测覆盖三值 + null + 混配存量。

## 6. 风险与开放问题

- 反向同步降级涉及旧客户端兼容窗口时长——需后端评估调用方清单后定期限。
- 声纹注册表迁移未核（§3.4 ⚠），若 Dev 证实存在云端注册特征，本单需追加迁移子项。
- Q2 未登录路径默认按评审立场实现（卡标需登录+置灰+去登录 CTA，不硬中断），如项目方改「强制登录引导」仅影响联网卡交互细节。
- 冻结包口径（Q6）变化需 DevOps 复核安装体积守护（AC-7 相关）。
