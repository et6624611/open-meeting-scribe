# PRD — 产品需求（骨架，待细化）

> 状态：占位。v1 施工细节以 [MVP_PLAN.md](../MVP_PLAN.md) 为准，本文后续沉淀稳态需求。

## 1. 目标用户
- 需要频繁开会、且要手动整理纪要的个人 / 小团队（如财务、项目、财税管理岗）。

## 2. 核心场景
| 场景 | 描述 | 版本 |
|------|------|------|
| 线上会议内录 | 腾讯会议/飞书等，一键录制系统声音 → 结束自动出纪要 | v1 (P2) |
| 音频文件转写 | 拖入已有录音（wav/mp3/m4a）→ 出纪要 | v1 (P1) |
| AI 对话驱动 | 通过自然语言对话完成录音、转写、查询、设置等操作 | v1 (P2) |
| 涉密会议 | 全程本地不上云 | v2 |
| 发言人姓名化 | 「说话人1」自动变「张三」 | v3/v4 ✅ |

## 3. 功能清单（v1）
- [x] 音频输入：文件拖拽 + BlackHole 实时内录
- [x] 转写 + 说话人分离（云端 paraformer-v2）
- [x] 热词增强（企业人名/术语）
- [x] 结构化纪要：结论 + 待办（谁/做什么/截止）
- [x] 本地 Web UI：左中右三栏布局（导航 / 主工作区 / AI 对话框）
- [x] AI 助手：对话驱动操作（录音、转写、查询、设置、热词管理）
- [x] CLI：`python cli.py transcribe <音频>`
- [x] 声纹姓名化（CAM++ 192维嵌入，注册后自动匹配）
- [x] GitHub OAuth 登录（JWT 会话管理）

## 4. 产品定位 · AI 对话是标配

AI 对话框不是附加组件，而是产品的**核心交互范式**：

| 维度 | 说明 |
|------|------|
| 交互方式 | 自然语言驱动全流程，降低学习成本 |
| 设置入口 | 对话可直接修改配置（模型、热词、API Key） |
| 上下文感知 | 对话与当前会议状态联动，支持追问 |
| 长期演进 | 从被动响应 → 主动助手（会前提醒、会中摘要、会后跟踪） |

## 5. 验收标准
- 给一段真实中文多人会议音频，产出**含发言人、可读、带结论与待办**的 Markdown 纪要。

## 6. 非目标（v1）
- 本地语音解析（v2 再议）、多语种、实时字幕。
