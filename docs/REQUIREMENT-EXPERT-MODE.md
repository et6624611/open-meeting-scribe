# REQ-EXPERT-MODE · 专家详情注释层 + 使用面闭环

## 1. 背景

现状「专家模式」是**形态错误**的第四张卡（role="switch" 装在 role="radiogroup" 里，AccessModeCards.vue:10/:91；箭头键只循环三卡 :224-231；文案自辩「作为第四种介入方式」i18n:170），开启后恢复的是**平行的旧版分类视图**而非同一模型加细节。同时配置栈真实深度为六层（L0 套餐→L1 决策→L2 参数→L3 本地资产→L4 CLI→L5 使用面），导航只给四个平级入口；对话面板**不能选模型**（后端 ChatRequest.model 已存在 chat.py:214，前端 useAiChat.ts:150 只带 engine，请求体既无 model 也无 mode → 永远默认 qwen-plus，chat.py:567/712）。

方向已由项目方确认：**同模型加细节层**（注释层，非平行界面）。

## 2. 范围

### 2.1 专家开关重定义
- 页面级开关，移出决策卡容器；`role=switch + aria-checked + tabindex`，Space/Enter 可切换；决策卡 `radiogroup` 内仅两卡，←/→ roving tabindex 循环。
- 开启效果 = 给**同一模型叠加注释层**：决策卡与六张详情卡各出现等宽工程值行（`engine.mode ▸ local`、`llm.provider ▸ preset`、`chat_engine.auth_tier ▸ readonly`、`asr.mode ▸ proxy|direct` 等）；流向矩阵显示工程值注释；「服务」「引擎」页出现底层字段。关闭后回到同一 access_mode 模型，**不出现任何平行界面**。
- 无障碍（裁决-5，产品级规则）：注释层 ≥12px、对比度 ≥4.5:1、等宽+`▸`键值对齐语法与 `.note` 说明文可区分；状态表达「色+文字+符号」三通道不单靠颜色。

### 2.2 配置栈六层重排
- 导航按 L0→L5 重排；L3 本地资产就绪度**前置回显到离线卡**（待就绪徽章+直达安装清单入口，消灭「决策卡与就绪详情分居两层」）；L4 CLI 引擎探针三段状态（路径解析 probe.py:63-70 → --version :73-76 → status 登录态 :94-108）常驻详情层回显，不再「撞错才知道」。
- 档位文案去写死：tierName()（SettingsView.vue:1462）改读账户真实档位，未来付费档接入即正确显示（【未来风险】提前治理）。

### 2.3 使用面闭环（第 6 刀）
- 对话面板增加**会话级模型选择器**：默认「跟随详情」，候选=预设模型/探测到的本机模型，每项标注来源（本机/体验配额/自带 Key）；前端接线补 `model` 字段（后端零改造，chat.py:214 契约不动）。
- 每轮回复尾部回显**实际消费方与计费口径**；现有引擎回显条（AiChatPanel.vue:122-127）保留并前置探针状态。
- 使用面回显卡（③ 详情层第六卡）随选择联动：`会话默认：跟随详情 · 来源：体验配额 · qwen-plus`。

## 3. 非目标

- 不改数据模型/写入口（REQ-SETTINGS-IA 范围）；不做旧版分类视图复活；不引入新组件库（维持手写 SFC + CSS 令牌口径）。

## 4. 验收标准

1. 专家开启/关闭全程**同一 DOM 结构增量显示**，无视图切换；键盘 Tab 走查：开关可达、aria-checked 同步、两卡 ←/→ 循环、焦点顺序一致（浏览器点验截图留痕）。
2. 注释层全部通过对比度自动化检查（axe 或脚本计算 ≥4.5:1 + ≥12px），作为 CI/点验门禁（产品级规则首次落地样本）。
3. 对话面板选模型后，请求体出现 model 且回复按所选模型生成；「跟随详情」时 llm.model 变更即时反映到下一轮；回复尾部消费方回显与 routing 实际判定一致（含计费口径）。
4. CLI 未安装/未登录两态：设置页详情卡直接可见失败段位（三段探针哪段挂），对话面板选智能体前即置灰+指引。
5. tierName 注入 mock 付费档后界面显示正确档位名（消灭写死）。

## 5. 风险

- 逐请求透传 model 与既有 per-engine 路由（智能体模式）的交互需在技术方案里明确优先级，防止第三种「界面说了不算」字段——验收标准 3 即为此设的闸。
- 依赖单未完成时本单注释层字段名可能变（proxy|direct 词表由 REQ-SETTINGS-IA §3.3 定稿），排期须串行。
