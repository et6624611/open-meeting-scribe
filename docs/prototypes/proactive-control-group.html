设计思路：胶囊控件组
  • 视觉统一：闪电 + 分隔线 + 齿轮封装在一个圆角胶囊（border-radius: 999px）内，通过边框和背景色形成明确的视觉边界，与 Tab 按钮通过 justify-content: space-between 自然分组
  • 状态 A→B 过渡：关闭态胶囊宽度 28px（仅闪电），开启态扩展至 56px（闪电 + 分隔线 + 齿轮）。宽度变化使用 cubic-bezier(0.4, 0, 0.2, 1) 缓动，分隔线和齿轮通过 width: 0→1px/28px + opacity: 0→1 同步渐入
  • 状态 B→C 过渡：设置面板通过 max-height: 0→280px 实现高度展开动画，齿轮图标旋转 90° 作为展开反馈。胶囊边框从 --proactive-mid 加深为 --proactive，背景从 --proactive-soft 加深为 --proactive-mid
  • 层级关系：Tab 按钮（左）←→ 控件组（右）通过 flex 两端对齐自然分离；控件组内部的闪电（主操作）和齿轮（辅助操作）通过 1px 分隔线区分主次
