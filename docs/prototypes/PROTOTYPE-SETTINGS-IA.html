改造原则六刀，按优先级（2026-09-26 裁决后版本）

1
决策层重构：三卡收敛为「离线 / 联网」两卡（体验不再占卡位）；详情层 = 能力级算力来源逐能力选择（LLM：体验 / 自带 Key / 本机端点；ASR：体验 / 自带 Key），账户「优先使用体验」勾选决定详情默认生效值并明示徽章。旧 route_override 静默语义整体消灭：配额耗尽、Key 缺失一律明示「自动改用」+ 常驻状态行（界面禁用「降级/兜底/fallback」词，用户看见的是换了计费方，不是系统做了个内部决定）。
2
单向数据流 + 保存语义统一：卡片是接入方式唯一写入口；参数编辑面收敛到「服务」（L2）一处、显式保存；引擎页 dropdown（SettingsView.vue:340-344）改只读徽章；卡片内联自动保存面板与跨屏草稿互见（AccessModeCards.vue:127 注释自认）一并废除。routers/settings.py:378 反向同步降级为旧客户端兼容窗口。
3
