# 企业版 P0 — 管理员手册（内网私有化）

这份手册面向"开通服务的那个人"。全程只有 3 个命令：安装、升级、回滚。

## 1. 准备一台公司服务器

- 系统：Ubuntu 22.04 / 24.04（P0 官方支持口径；Windows Server 可参考本文自行安装 Docker Desktop/WSL2，暂不承诺验收）
- 安装 Docker Engine 与 compose v2 插件（公司无外网时，Docker 安装包也在离线交付包里向软件供应商索取）
- 把企业版交付包整个拷贝到服务器，例如 `/opt/oms/`（包内 `images/` 已含应用镜像与加密访问所需 Caddy 镜像的 tar，安装全程不需要外网拉取）

## 2. 安装（一条命令）

```
sh deploy/private 所在目录
./oms-offline-install.sh
```

脚本会自动：载入离线镜像 → 生成配置 → 启动服务 → 体检通过 → 打印访问地址。

然后**在这台服务器的浏览器里**打开 `http://localhost:8000`，按初始化向导：
1. 设置管理员账号（用您的手机账号注册，即存量数据归属账号 13373013103）；
2. 确认员工访问地址；
3. 生成邀请码，把地址和邀请码发给同事。同事自己设密码，您不经手任何密码。

向导完成后，同事用浏览器访问打印出来的地址即可使用。如果您以前在个人版单机里存过会议内容，看下一节把它们搬进来。

## 3. 把个人版的老数据搬进来（如有）

只搬文字内容（会议转写、纪要、决策、笔记、热词、发言人昵称），**录音和音频仍留在原电脑，不会被上传**；老电脑的个人版完全不受影响。

1. 把老电脑上个人版的数据文件夹整个拷贝到服务器本目录，命名为 `old-data`；
2. 在服务器上执行：

```
docker compose run --rm --volume "$PWD/old-data:/data/legacy:ro" oms-app \
  python -m app.db migrate-legacy --source /data/legacy --account 13373013103
```

3. 命令会输出搬入数量；对账明细自动写在 `data/logs/migration_report_<时间>.json`；
4. 重复执行安全（已搬过的内容不会重复导入），随时中断后可直接重跑。

## 4. 要不要开加密（建议开）

默认内网明文访问——能用，但同事的密码和会议文字在内网可被抓包。
开启方式：编辑 `.env` 把 `OMS_TLS_MODE=off` 改为 `internal-ca`，重跑 `./oms-offline-install.sh`
（脚本自动生成企业根证书并为服务器 IP 签发证书；服务器换 IP 后重跑一次即自动重签）。
之后把 `ca/oms-root-ca.crt` 和 ca/ 目录里的导入脚本发给员工（每台电脑执行一次），
同事改用 `https://<服务器IP>:8443` 访问。也可用 `custom-cert` 换企业自己的证书，员工零操作。

## 5. 日常运维

- 服务状态：`docker compose ps`；日志：`docker compose logs -f oms-app`
- 备份：全自动，每天一次存在 `backups/`，保留 14 天。
  **企业数据备份只保留在这台服务器上，永不上传外部云**（产品对外承诺口径）。
- 扩容磁盘/搬家：整个目录（含 data/ backups/）拷到新机后重跑安装脚本即可。

## 6. 升级与回滚

```
./oms-upgrade.sh 新版本镜像.tar     # 自动：备份 → 迁移 → 替换 → 体检，体检不过自动回滚
./oms-upgrade.sh --rollback         # 手动切回上一版本
```

极端情况（数据损坏）：停止服务，把 `backups/` 里最近一份 `instance_<时间>.db` 与
`snap_<时间>.tar.gz` 恢复到 `data/`，再跑一次安装脚本。升级前那次强制备份就是还原点。

## 7. 忘记管理员密码

在服务器上执行（只允许本机运行，不依赖短信或任何外部渠道）：

```
docker compose exec oms-app python -m app.db admin reset-password --account <管理员登录名/手机号>
```

命令输出一个**一次性重置邀请码**，管理员本人走正常的"邀请码自助设密码"流程完成重置：
执行命令的人从头到尾不经手明文密码（与"管理员不经手密码"的口径一致），
同时旧登录会话和已绑定设备全部作废。
